# 📊 Web Traffic Analytics Dashboard

An end-to-end **Data Analytics** project that analyzes website traffic data to understand user behavior, evaluate engagement metrics, identify high-performing traffic sources, and generate actionable business insights. The project combines **Python**, **Pandas**, **Plotly**, and **Streamlit** to create an interactive analytics dashboard suitable for business decision-making.

---

## Project Overview

Understanding website traffic is essential for improving user engagement and increasing conversion rates. This project performs exploratory data analysis (EDA) on website traffic data and presents the findings through an interactive Streamlit dashboard.

The dashboard enables users to explore traffic patterns, analyze user engagement, evaluate marketing channels, and generate business recommendations.

---

## Objectives

* Analyze website traffic patterns.
* Measure user engagement using key metrics.
* Compare traffic sources.
* Study bounce and conversion behavior.
* Identify relationships between website metrics.
* Build an interactive business dashboard.
* Generate actionable business recommendations.

---

## Dataset

The dataset contains website engagement metrics including:

| Feature          | Description                                 |
| ---------------- | ------------------------------------------- |
| Page Views       | Number of pages viewed                      |
| Session Duration | Total session duration (seconds)            |
| Bounce Rate      | Percentage of users leaving after one page  |
| Traffic Source   | Visitor acquisition channel                 |
| Time on Page     | Average time spent on page                  |
| Previous Visits  | Number of previous visits                   |
| Conversion Rate  | Percentage of users completing a conversion |

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Web-Traffic-Analytics.git
```

Navigate to the project folder

```bash
cd Web-Traffic-Analytics
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the dashboard

```bash
streamlit run dashboard/dashboard.py
```
